## 3. Game Title Artwork Assets (Remote Sourcing Architecture)

**Architecture Evolution:**  
To eliminate the requirement of manually downloading, storing, and maintaining hundreds of local image files in the repository, NostalgicVerse employs a **Remote Image Loading Architecture** prioritizing verified direct external image URLs (`https://...`) backed by the permanent Museum Accession Fallback Plate system.

**Display Priority Hierarchy:**
```
LOCAL VERIFIED ASSET (On-Disk)
         ↓
REMOTE VERIFIED ASSET (Direct Image URL)
         ↓
MUSEUM ACCESSION FALLBACK PLATE (Graceful Degradation via onerror)
```

## 17. Asset Naming Rules & Conventions

1. **Strict Lowercase Kebab-Case:** All filenames must consist solely of lowercase ASCII letters, numerals, and single hyphens (e.g. `nintendo-64.png`, `pac-man.webp`).
2. **Forbidden Patterns:** Filenames must never include:
   - Spaces (e.g. `Generated Image.png`)
   - Timestamps (e.g. `September 10, 2026 - 3_41PM.webp`)
   - Copy duplicates (e.g. `(1)`, `(2)`, `_copy`)
   - Random machine hashes or camera tags (e.g. `IMG_4091.jpg`)
3. **Format Standards by Category:**
   - **Console Hardware Cutouts:** `.png` (True 32-bit RGBA with transparent background).
   - **Operating System Logos:** `.png` (True 32-bit RGBA with transparent background).
   - **Game Title Artwork / Box Art:** `.webp` (Optimized lossy/lossless WebP, max quality 90-92).
   - **Guide Illustrations / Technical Graphics:** `.webp`.
   - **Story & Essay Header Art:** `.webp`.
   - **Brand Vector Marks:** `.svg`.
   - **Favicon:** `.ico`.
